# Trakt Scrobbler Plus v0.2.8 — Stable

Promoted from `v0.2.8-beta.1` after macOS Light/Dark UI validation alongside Episode Info Plus v1.3.3. This is a **UI-only** release: identity/matching, Trakt API calls, scrobble state, OAuth credentials, watch history and queue handling are unchanged.

## New in v0.2.8

- Shared semantic native-glass palette with Episode Info Plus for macOS Light and Dark appearances.
- Retains the transparent IINA sidebar while improving borders, text/surface consistency and translucent authentication/code-box surfaces.
- No change to enabled/disabled scrobbling, show OSD settings, Trakt Resume Protection, correction workflow, diagnostics, or video control behavior.
- Previous v0.2.7 matching support is retained: validated The Diplomat (US) country-alias exact episode matching and Poetic Justice (1993) movie-only AIOStreams fragment parsing, as well as Comet, Yastream, MediaFusion and DMM safeguards.

## Versioning and upgrade

- Official plugin identifier: `io.github.olivergiangvu.iinatraktscrobblerplus`.
- `ghVersion=28`, increasing from beta.1's 27 and v0.2.7 Stable's 26, enabling clients already on the beta to receive Stable.
- Install `Trakt-Scrobbler-Plus-v0.2.8.iinaplgz` from GitHub Releases or through IINA's plugin GitHub installer.
- The existing connected Trakt account and preferences stay in place. Users should keep any original standalone Trakt scrobbler disabled to avoid duplicate tracking.
- No change to IINA, HomeDocker, CrossWatch, Trakt Bridge or Episode Info Plus behavior; the two plugins remain independent.
- Node smoke tests, PR validation and release package/archive checks are required before this becomes GitHub Latest.

Rollback: previous v0.2.7 Stable remains available from Releases.
