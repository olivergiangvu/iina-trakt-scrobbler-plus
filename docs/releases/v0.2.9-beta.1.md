# Trakt Scrobbler Plus v0.2.9-beta.1 — AIOStreams Duplicate Series Identity

This **prerelease** fixes scrobble deadlocks for same-title series in v0.2.8.
It has not yet passed IINA/macOS field testing. Latest Stable stays v0.2.8.

## Changes
- For a structured `#aios_title` episode such as `The Diplomat · S02E04 · The Other Army`,
  Trakt+ no longer treats same-title shows as impossible to differentiate.
- Retrieves the candidate's exact Trakt season/episode metadata; auto-resolves
  **only when exactly one** of up to eight candidates matches the exact episode
  title and no search page is truncated. Missing title or ambiguous evidence
  remains blocked and requires Manual Match.
- Protects title-sensitive verification cache from an unrelated episode title.
- Resume Protection now displays actionable **Correct Match** guidance when
  the Trakt show identity is unverified, and HTTP 429/503 when the read-only
  resume endpoint fails. It still never sends unsafe early progress.
- After a successful Trakt resume preflight, Match Source reports
  **AIOStreams Title (Trakt Exact)** even before the next scrobble.
- No changes to player URL, IINA mpv_start, AIOStreams, MediaFusion, HomeDocker
  or the independent Trakt Bridge. Existing stop queue and resume safeguards stay.

## Mac acceptance
1. Open *The Diplomat S02E04 — The Other Army* through the same AIOStreams
   custom player URL; Match Source should become Trakt Exact and resume sync.
2. Confirm `Watching on Trakt` and actual downstream AIOStreams resume.
3. On a genuinely ambiguous show/episode, expect explicit Needs Match and
   **no** scrobble, never a wrong title.
4. Verify existing Comet, DMM, MediaFusion and prior Yastream test cases
   remain functional.

Rollback: `v0.2.8` stable is unchanged.
