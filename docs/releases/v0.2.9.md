# Trakt Scrobbler Plus v0.2.9 — Stable

Promoted from the v0.2.9-beta.6 IINA canary on 7 November 2026 following regression CI and macOS field validation. This stable release includes the v0.2.9 identity framework and fixes the observed Guessit parsing ambiguity for `The.Season.2026.S01E01.mkv`.

## What changed

- **Explicit season/episode wins:** a real `SxxExx` marker takes priority if Guessit incorrectly interprets a show title containing the word "Season" and a four-digit release year as a season number. `The.Season.2026.S01E01.mkv` → `The Season`, **S01E01**, not `The`, S2026E01.
- **Strict Trakt identity workflow:** retains read-only candidate lookup, external-ID verification and exact show/episode checks. Unmatched or ambiguous shows never automatically scrobble. Correct Match can securely confirm a show, after which subsequent episodes can be independently verified through Trakt without repeating the manual selection.
- Retains v0.2.9 beta identity/caching improvements, redacted Copy Diagnostics and conservative Trakt Resume Protection. No bypass for missing external ID; manual confirmation remains valid evidence only after Trakt validates the selected episode.
- Retains existing v0.2.8 native Glass UI, Sync Queue, recently confirmed stops, network pacing, resume/stop persistence and security protections.

## Mac/IINA acceptance

User-provided IINA screenshots and redacted plugin diagnostics for `v0.2.9-beta.6`:

1. **The Season S01E01:** parser identifies `title=The Season, season=1, episode=1`; initially unverified, Resume Protection correctly blocks scrobbling.
2. **Correct Match:** after user selection, `Manual Confirmed`, `Watching on Trakt` and proper `traktTarget` for S01E01.
3. **The Season S01E02:** `Trakt Verified`, `Watching on Trakt`, `traktTarget=The Season S01E02 - A Horse Named Alison`, without another Correct Match. `0 pending · 0 needs review`.
4. **Hell Barrister S01E01:** verified Trakt match and successful pause event, and prior `Recently Synced` confirmations for earlier episodes.

**Important acceptance boundary:** The new screenshots confirm Trakt *start/playing* and a paused event, but do **not** independently prove that the final stop from The Season was saved to remote Trakt watched history. The existing stop/checkpoint implementation retains prior regression coverage; users should verify history after their next completed playback. Do not claim that unverified titles can be scrobbled safely.

## Versioning, upgrade and rollback

- Version `0.2.9`, `ghVersion=35`; rises above beta.6 (34) and previous stable v0.2.8 (28) so IINA can detect the stable update.
- Official IINA identifier unchanged: `io.github.olivergiangvu.iinatraktscrobblerplus`. Trakt OAuth pairing and plugin settings remain in the existing installation.
- Install `Trakt-Scrobbler-Plus-v0.2.9.iinaplgz` from [GitHub Releases](https://github.com/olivergiangvu/iina-trakt-scrobbler-plus/releases) once available, or use IINA's GitHub plugin update.
- Rollback: reinstall the prior **v0.2.8 stable** release asset. Do not run Trakt+ alongside the original Trakt scrobbler with scrobbling enabled (duplicates).

## Scope

No changes to AIOStreams, Episode Info Plus, HomeDocker, Trakt Bridge, Metadata Bridge or production containers. This is the Trakt+ IINA plugin release only.
