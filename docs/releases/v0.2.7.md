# Trakt Scrobbler Plus v0.2.7 — Stable

Promoted from **v0.2.7-beta.2**, tested in the user's official IINA 1.5.0 + AIOStreams + Trakt setup. The final release preparation modifies version metadata, documentation and packaging validation **only**; playback identification, title resolution, resume protection, Trakt API writes, and diagnostics code are unchanged from the field-tested beta.2 canary.

## New in 0.2.7

### 1. Country-suffix TV-series alias matching (beta.1)

AIOStreams and TheTVDB sometimes label a series differently from Trakt. The observed example was **The Diplomat (US) S01E06 — Some Lusty Tornado**, for which Trakt's canonical show name is **The Diplomat**.

- Existing `#aios_title` extraction remains supported through the official IINA/mpv URL path.
- With no unique exact-title match, allow only a bounded trailing country suffix (`US`, `UK`, `AU`, `CA`, `NZ`) to be stripped as a **candidate search**.
- Corroborate production year from a *matching* readable filename such as `The.Diplomat.2023.S01E06.mkv`; never infer a year from opaque stream paths.
- Independently verify exact season, episode and **episode title** against Trakt; allow automatic matching only if exactly one candidate passes. Wrong year, missing or mismatched episode titles, duplicate matches and Trakt API failures all fail closed (manual correction remains available).
- **Mac field test: PASS.** The Diplomat (US) S01E06 was identified as The Diplomat S01E06 and was scrobbled to the correct Trakt show.

### 2. AIOStreams movie metadata handling (beta.2)

AIOStreams Custom Links supply a single movie title rather than an `SxxExx` label. In v0.2.7-beta.1, a movie-only `#aios_title` such as `Poetic Justice` was rejected before filename parsing, yielding **No active media** although the movie played normally.

- Recognize movie-only fragment metadata and make an active **movie** candidate.
- Recover the production year only from an accompanying, readable filename with the same normalized title (e.g. `Poetic.Justice.1993.mkv#aios_title=Poetic Justice` → **Poetic Justice (1993)**), or a consistent explicitly declared year.
- Require **one unique exact movie title and production year** in Trakt and re-verify canonical detail before scrobbling. Movie title alone (e.g. a generic `index.m3u8` HLS source with no trusted year) remains unverified and must not send an automatic scrobble.
- Reject ambiguous titles/years and conflicts rather than choosing the highest-scored unrelated movie.
- Allow **Copy Diagnostics** even when playback metadata cannot be identified, using the existing redacted diagnostic builder.
- **Mac field test: PASS.** Poetic Justice (1993) displayed **AIOStreams Title (Trakt Exact)** and **Watching on Trakt**, with matching target `Poetic Justice (1993)`.

### 3. Regression / safety checks

- Node smoke tests and pull-request validation full suite, including package/archive checks, passed on the tested beta.2.
- Tests cover regional aliases, false candidate matches and duplicate shows, exact episode titles, movie title/year identity, ambiguous movies, missing movie year, canonical detail verification, and diagnostic availability without an identified session.
- Existing v0.2.6 verified Yastream S01E10 episode matching and manual Season/Episode correction, Comet ID verification, MediaFusion/DMM safeguards, durable stop journal and Trakt Resume Protection are retained without behavior changes.

## Production configuration

- **IINA:** official 1.5.0; all S/PDIF passthrough codecs OFF in IINA → Settings → Audio for the previously observed AVFoundation startup issue.
- **AIOStreams Custom Link (unchanged):**

```text
iina://weblink?url={encodedUrl}%23aios_title%3D{title}&mpv_start={position}
```

- **Trakt Scrobbler Plus:** v0.2.7, `ghVersion=26` (higher than beta.2's 25).
- Install using IINA → Settings → Plugins → Install from GitHub with `olivergiangvu/iina-trakt-scrobbler-plus`, or open the attached `Trakt-Scrobbler-Plus-v0.2.7.iinaplgz`.
- Episode Info+, HomeDocker, Trakt Bridge, other trackers and official IINA are **not modified**.

## Limits and rollback

Metadata sent in `#aios_title` is context, not a verified ID. A series alias must have a unique Trakt match and a verified episode; movie title-only sources with no independently corroborated year require Manual Match. Localized/nonmatching titles and certain remakes may still need manual confirmation.

Previous stable **v0.2.6** and the field-tested **v0.2.7-beta.2** canary remain rollback references. Do not disable Trakt Resume Protection to force scrobbling.
