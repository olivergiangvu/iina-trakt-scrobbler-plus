# Trakt Scrobbler Plus v0.2.9-beta.2 — Strict Show Identity Canary

## Incident
`The.Night.Manager.2016.S01E02.mkv` was correctly recognized as a 2016 episode but mapped to Trakt show 202191 (India, 2023), instead of 94686 (UK, 2016). The plugin persisted `the night manager|2016 -> 202191` as `verified:true`.

## Changes
- Require exact normalized show title and matching production year when filename provides the year, before episode lookup.
- Filter conflicting-year candidates, reject ambiguous/truncated searches, and never use high Trakt relevance alone as identity proof.
- Reject generic episode titles like `Episode 2` as disambiguating evidence.
- Require fresh verification of pre-v2 `verified:true` cache entries; v2 records store proof source, show year, title key, IMDb if available, and proof version.
- Scope S/E-dependent proof to that exact S/E; another episode does not inherit the identity automatically.
- Keep user-supplied Correct Match and confirmed-ID paths.
- New mocked regression tests include the Night Manager 2016/2023, same-title/same-year ambiguities, wrong legacy verified cache, and episode-to-episode proof isolation.

## Mac canary precautions
This is a **GitHub Actions artifact**, not a stable release. No production Trakt history, HomeDocker stack or Mac installation is modified automatically.

1. **Before restarting IINA**, check the existing Trakt+ Pending/Syncing queue. A persisted pending final STOP may replay on startup. Back up plugin data and existing plugin package.
2. Download the zip artifact from the **Build v0.2.9-beta.2 Identity Canary** workflow on branch `fix/v029-strict-show-identity-cache-v2`; extract the nested `.iinaplgz` file and checksum.
3. Use IINA's plugin installation flow to open the new `.iinaplgz`, then restart IINA only when no unintended pending final STOP remains. Verify Trakt+ shows `0.2.9-beta.2`.
4. Disable scrobbling until confirming playback matching for UK **The Night Manager (2016)** S01E01/S01E03. Expected: Trakt show 94686, not 202191. Confirm cache `identityVersion:2`, `trakt:94686`, `showYear:2016`.
5. Check another already working title such as Heart Code. Avoid sending new Trakt scrobbles during identity diagnostics. Only enable scrobbling and run a brief controlled playback after checking the target.
6. If any identity is ambiguous, expected behavior is **Correct Match required**, not a guessed POST. Roll back to the backed-up previous package if playback is affected.
