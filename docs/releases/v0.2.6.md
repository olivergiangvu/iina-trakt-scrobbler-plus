The user confirmed safe automatic Trakt scrobbling for an AIOStreams/Yastream HLS episode and previously confirmed the **v0.2.6-beta.1** manual Season/Episode editor hotfix. ## What's new since v0.2.5

### 1) AIOStreams HLS episode automatching without an IINA fork

AIOStreams can embed its known show/episode metadata in a URL fragment that IINA/mpv preserves in `path`. The Trakt+ plugin separately extracts `#aios_title=...` and validates a structured `Show · S01E10 · Episode title` value instead of guessing from the generic HLS filename `index.m3u8`.

Set the AIOStreams **Custom Link** to:

```text
iina://weblink?url={encodedUrl}%23aios_title%3D{title}&mpv_start={position}
```

The link leaves the actual HLS HTTP request and resume-start parameter unchanged. It is not a native IINA metadata API; it relies on mpv retaining the URL fragment, **confirmed for this setup**. No custom IINA build or auxiliary proxy/daemon is needed.

### 2) Guard against false-positive Trakt scrobbles

- A fragmented HLS title is **a candidate, not identity proof**.
- Trakt+ requires **one unique, exact canonical series-title match** and independent confirmation that the exact Season/Episode exists before scrobbling.
- Rejects the previously observed incorrect match of `index.m3u8#aios_title=...` to *A Certain Magical Index*.
- Rejects malformed/conflicting fragments and multiple exact-title series; requires Manual Match if ambiguous.
- Stores only verified, episode-scoped match-cache data; no playback stream URL, access token or HLS credentials are written as match keys.

### 3) Manual Match editor reliability

- Season/Episode fields use text-numeric entry rather than unreliable WKWebView number spinners.
- In-progress S/E values survive sidebar refreshes and Trakt search rerenders.
- Reset inputs appropriately on correction close, media change and Movie/Series selection.
- Manual corrections still verify the chosen show and S/E with Trakt before scrobbling.
- Field-tested with *OK! Let's Get Divorced* S01E10 via Yastream.

### Existing capabilities carried forward

Fresh IMDb/TMDB verification, Comet episode matching, Trakt resume preflight and manual restore, DMM/MediaFusion fail-closed metadata handling, durable Trakt stop journal, batched diagnostic logging, Live Trakt sync and AIOStreams watched-state integration remain as in stable v0.2.5.

## Setup, known limits and rollback

- Official IINA 1.5.0; leave S/PDIF passthrough codecs OFF for the tested AVFoundation startup-seek configuration.
- IINA → Settings → Plugins → Install from GitHub: `olivergiangvu/iina-trakt-scrobbler-plus`.
- Alternative: open the attached `Trakt-Scrobbler-Plus-v0.2.6.iinaplgz` with IINA.
- Version `0.2.6`, auto-update `ghVersion=23` (> beta.2's 22).
- **No changes** to Episode Info+, HomeDocker, Trakt Bridge or other tracker services. Episode Info+ handles its own metadata matching separately.
- The structured fragment format currently supports TV episodes containing SxxExx; movies, localized titles that differ from Trakt, or homonymous series may still need Manual Match. A title fragment alone does not supply IMDb/TMDB and is not definitive identity proof.
- Previous stable **v0.2.5** and tested canary **v0.2.6-beta.2** remain available as rollback options.
