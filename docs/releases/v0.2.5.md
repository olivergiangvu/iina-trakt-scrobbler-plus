# Trakt Scrobbler Plus v0.2.5 — Stable

Promoted from **v0.2.5-beta.7** after macOS/IINA field testing (4/4 acceptance cases PASS) and automated regression tests. This release changes only release metadata, documentation and packaging relative to the tested beta.7: no additional changes to playback identification, Trakt API write logic or resume behavior.

## What's new since v0.2.4

- **Fresh IMDb/TMDB identification.** Explicit source IDs (for example `media_id=tt...`) are verified with Trakt on first playback, including the exact TV season and episode. Wrong/mismatched IDs fail closed rather than sending a false watched entry.
- **Comet episode recognition.** When a trusted Comet URL contains the show's IMDb ID but omits season/episode fields, use a confidently parsed filename's S/E **only after** matching the resolved Trakt series title and verifying that the episode exists. Field-tested with Better Call Saul S03E03/S03E04.
- **Resume Overwrite Protection.** Read-only Trakt resume preflight occurs before scrobbling. If the remote checkpoint is ahead or the lookup is unavailable, do not overwrite it. Restore the Trakt position only with explicit user action; do not silently auto-seek.
- **Debrid Media Manager filename safety.** Recognize `file=` release names within opaque DMM paths without treating token/hash query strings as titles. Diagnostics redact stream secrets.
- **Sidebar and diagnostics hardening.** Clearer Manual Match / Resume Protection status and throttled playback-status updates. Diagnostic `debug.log` writes are batched (8 KB or 10 seconds), flushed on window close/shutdown, and retain only the latest 200,000 characters. Durable Trakt stop checkpoints remain separate.
- Preserves manual Match Correction, verified MediaFusion pack matching, Match Provenance, Sync Queue, rate-limit/backoff controls and safe interrupted-stop retries from v0.2.4.

## Validated acceptance

Field-tested on official IINA 1.5.0 / macOS with AIOStreams and Comet:

- Start playback at an existing mid-episode resume position: **PASS**.
- Save sub-watched Trakt progress on pause/stop: **PASS**.
- Record watched on Trakt and observe AIOStreams watched-state synchronization: **PASS**.
- Quit and relaunch IINA, preserving checkpoint/recovery: **PASS**.

Note: the watched-state sync observed in this setup does **not** imply every external AIOStreams client or provider supports automatic bidirectional resume.

## IINA playback configuration

One tested IINA 1.5.0 setup got stuck on initial `Seeking…` while sending `spdif-ac3` through the AVFoundation audio driver. **Disabling all S/PDIF passthrough codecs in IINA → Settings → Audio** restored automatic initial playback on the affected stream. This is an **IINA setting**, not a Trakt+ code change.

Retain the AIOStreams Custom Link:

```text
iina://weblink?url={encodedUrl}&mpv_start={position}
```

No custom IINA build, separate process or HomeDocker/Trakt Bridge change is required.

## Installation and rollback

Install or update using **IINA → Settings → Plugins → Install from GitHub**, repository `olivergiangvu/iina-trakt-scrobbler-plus`, or install the `Trakt-Scrobbler-Plus-v0.2.5.iinaplgz` file attached to this release. The plugin identifies as `v0.2.5` with `ghVersion=20`.

Keep the original Trakt Scrobbler plugin disabled to prevent duplicate events. Previous stable `v0.2.4` remains available for rollback; the tested `v0.2.5-beta.7` package is also retained separately.

**Known limitation:** If neither URL nor filename/player metadata provides a trustworthy show ID, localized MediaFusion episode names may still require a manual confirmed match. The plugin does not guess unverified series identities.
