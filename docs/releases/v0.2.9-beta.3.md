# Trakt+ v0.2.9-beta.3 — Structured HLS media-title parser canary

A generic HLS `index.m3u8` stream may expose a readable mpv media-title:
`City of Splendour · S01E01 · Episode 1`. Previously, the middle-dot
separator could leak into the show title (`City Of Splendour ·`).

This canary converts only anchored, structured `Show · SxxExx · Episode`
labels before existing episode parsing. It does **not** trust an opaque
stream URL, invent external IDs or bypass strict Trakt show verification.
The Trakt catalogue may call the Hong Kong 2026 series
`This City Never Sleeps` / `璀璨之城`; if no exact Trakt show/episode
can be proven, auto-scrobbling must remain disabled pending Correct Match.

Based on the v0.2.9-beta.2 identity-cache v2 safety work.
Regression suites and packaging run in GitHub Actions; no GitHub release.
PR #16 is review-only, stable v0.2.8 remains unchanged.
